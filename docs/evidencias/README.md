# Evidências visuais — GeniOS

Este índice cataloga as **104 capturas** recebidas no arquivo `prints-genios.zip`, preservando a separação original por perfil. As legendas abaixo foram elaboradas a partir dos nomes dos arquivos; descrevem o assunto indicado pelo nome e não substituem a inspeção do conteúdo visual.

## Como adicionar as imagens ao repositório

Extraia o ZIP e copie a pasta `prints-genios` para este diretório, mantendo os nomes e subpastas. A estrutura final esperada é `docs/evidencias/prints-genios/<perfil>/<arquivo>.png`. Depois, faça commit dos arquivos PNG. **Neste commit está sendo criado apenas o índice textual; as imagens binárias ainda precisam ser enviadas ao GitHub.**

## Uso como evidência

As capturas podem apoiar a demonstração das telas, dos perfis, dos controles de acesso e dos fluxos indicados em cada legenda. Elas não comprovam, isoladamente, execução de testes automatizados, respostas HTTP não visíveis ou resultados de cenários que não estejam representados na imagem. Relacione cada print ao caso de teste correspondente e registre separadamente data, ambiente, usuário/perfil e resultado observado.
